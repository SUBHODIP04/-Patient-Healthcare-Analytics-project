🏥 Patient Healthcare Analytics Dashboard | Power BI
📌 Project Overview
This project presents an interactive Patient Healthcare Analytics Dashboard developed using Microsoft Power BI.

The dashboard analyzes patient demographics, medical conditions, hospital admissions, billing amounts, insurance providers, and length of hospital stays to provide meaningful healthcare insights and support data-driven decision-making.

The objective of this project is to transform raw healthcare data into an interactive and easy-to-understand business intelligence dashboard.

🎯 Project Objectives
Analyze overall patient demographics and healthcare trends.

Identify the most common medical conditions.

Analyze total and average healthcare billing.

Compare billing across different years.

Analyze hospital admission patterns.

Understand insurance provider performance.

Analyze average patient length of stay.

Identify hospitals with higher patient volumes and billing.

Provide interactive filtering for better decision-making.

🗂️ Dataset Information
The dataset contains patient-level healthcare information, including:

Column	Description
Name	Patient name
Age	Patient age
Gender	Patient gender
Blood Type	Patient blood group
Medical Condition	Primary medical condition
Date of Admission	Patient admission date
Doctor	Treating doctor
Hospital	Hospital name
Insurance Provider	Insurance company
Billing Amount	Total billing amount
Room Number	Assigned room
Admission Type	Type of admission
Discharge Date	Patient discharge date
Days Admitted	Length of hospital stay
Medication	Medication prescribed
Test Results	Medical test result
